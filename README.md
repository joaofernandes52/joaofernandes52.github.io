# João Fernandes - Portfolio

This is the source code for my personal portfolio, built with React, TypeScript, and Tailwind CSS.
It features smooth animations and a modern design.

## Technical Stack
- React
- TypeScript
- Tailwind CSS
- Framer Motion

## Running Locally

1. Clone the repository
2. Install dependencies: \`npm install\`
3. Run the development server: \`npm run dev\`
4. Build for production: \`npm run build\`
